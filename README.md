# Scrap Corsairs: builds

Aquí se publican las versiones del juego para jugar con los amigos. El código no está aquí.

## Cómo jugar
1. Entra en **Releases** (a la derecha) y descarga `ScrapCorsairs.exe` de la última versión.
2. Guárdalo en una carpeta tuya (por ejemplo, `Documentos\Scrap Corsairs`) y ábrelo.
3. La primera vez, Windows puede avisar (SmartScreen: «Más información» → «Ejecutar de todas formas») y preguntar por el cortafuegos: «Permitir».

## Actualizaciones
Desde la 1.6, al abrir el juego el menú avisa si hay una versión nueva. Pulsa **Actualizar**: se descarga, el juego se cierra y se abre ya actualizado.

Tus partidas guardadas no se tocan: están en `%APPDATA%\Godot\app_userdata\Scrap Corsairs\`, no junto al `.exe`.

Las novedades de cada versión están en `CHANGELOG.md` y en cada release.
